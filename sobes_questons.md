    🧠 Алгоритмы и структуры данных
    - Что такое Big-O? Приведи примеры
        Это математическая оценка эффективности алгоритмов, которая показывате как меняется время выполнения или объем используемой памяти при увеличении объема входных данных. Описывает верхнюю границу, т.е. худший сценарий. Пример оценки алгоритмов: пузырьковая сортировка O(n^2), быстрая сортировка O(n * logn), сортировка вставками - O(n)
    - Разница между O(n), O(log n), O(n²)
        Разница в скорости роста времени выполнения алгоритма при увелечении объема данных. O(n^2) самая медленная, O(nlogn) уже быстрее, но идеал, а O(n) в данном случае будет быстрее всех 
    - Что такое массив vs связный список?
        массив - это упорядоченный набор данных одного типа, хранящихся в памяти последовательно, с быстрым доступом по индексу. Связанный список, это набор узлов (данные и ссылка на след. узел), разрабросанных в памяти и соеденынных указателями. Разница в ключевых факторах:
        * Доступ к элементам: в массиве O(1). в списке O(n)
        * Память: массив требует непрерывного блока памяти, а список нет, т.к. узлы размещаются в свободных местах памяти
        * Вставка/удаление: у массива медленные, тк нало двигать элементы, у списка быстрые 
    - Как работает хеш-таблица?
        хэш-таблица - это структура данных, реализующая интерфес ассоциативного массива (тип данных который хранит ключ значение), позволяет хранить пары (ключ,значение) и поддерживает три операции: добавление новой пары, удаление и поиск пары по ключу
    - Коллизии в hash map — какие бывают способы решения?
        Коллизии в хэш мапе - это ситуация, когда разные ключи имеют одинаковый хэш код или попадают в одну корзину, что неизюежно при несовпадении количества элементов и возможных значений хэша
        методы решения - метод цепочек, открытая адресация
        Метод цепочек - каждая ячейка хэш таблицы содержит не один элемент, а указатель на связанный список пар (ключ,значение)
        Открытая адресация - все пары (ключ, значение) хранятся непосредственно в массиве. При коллизии ищется другая свободная ячейка по определенному правилу
    - Что такое стек и очередь? Где применяются?
        Стек и очередь - этло линейные структуры данных, которые упорядочивают элементы. Стек работает по принципу LIFO ( последним пришел, первым ушел), а очередь по FIFO (первым пришел, первым ушел). 
        стек применяется в : отмена операция (Ctrl + Z ), история браузера (нажатие кнопки назад), стек вызовов
        очередб применяется в: очередь сообщений, обработка запросов, потоковое видео 
    - Что такое рекурсия? Когда её лучше не использовать?
        Рекурсия - это процесс, при котором алгоритм или функция вызывает или описывает саму себя, используя самоподобие. Рекурсию не стоит использовать при большой нагрузке на память (риск переполнения стека), глубокой рекурсии или когда итеративный цикл проще и быстрее
    - Что такое бинарный поиск? Когда он работает?
        Это высокоэффективный алгоритм нахождения алгоритма в отсортированном массиве, работающий по принципу деления пополам. На каждом шаге средний элемент сравнивается с искомым, если они не равны, то поиск продолжается в той половине, где может находится элемент. Работает за время O(nlogn). Работает когда массив отсортирован
    - Что такое граф? Какие бывают обходы (DFS, BFS)?
        Граф - это абстрактная структура данных, моделирующая связи между объектами. Она состоит из конечного набора вершин (узлов) и соединяющих их ребер (дуг).
        Бывают ориентированные графы (связи имеют направление), неориентированные графы (связи без направления), взвешенные графы (связи имеют вес).
        DFS (Deep first search) - это поиск в глубину. Выбирается одна вершина, затем алгоритм идет по ребру к следующей, пока не достигнет тупика, после чего возвращается назад
        BFS (Breadth first search) - поиск в ширину. Сначала посещается начальная вершина, потом все ее соседи, потом соседи соседей и так далее.
        Время обоих алгоритмов - O(V + E) V - вершины, E - ребра 
    - Что такое динамическое программирование?
        Это метод решения вычислительных задач, основанный на разбиении их на более мелкие, перекрывающиеся подзадачи. Основной принцип заключается в сохранении результатов уже решенных подзадач, чтобы не вычислять их заново. Применяется для задач оптимизации (найти самый быстрый, самый дешевый и тд)

    🧩 Память и управление ресурсами
    - Что такое стек и куча (stack vs heap)?
        Стек и куча - это две основннеы области оперативной памяти, используемой программами. Стек работает автоматически, хранит локальные переменные и работает по принципу LIFO, обеспечивая высокую скорость. Куча - это большое, неорганизованное хранилище для динамических данных, требующих явного или автоматического управления, работает медленее стека  
    - Как работает garbage collector?
        Это автоматический механихм управления памятью, который работает в фоновом режиме, определяя и удаляя неиспользуемые объекты для освобождения памяти
    - Что такое утечка памяти (memory leak)?
        Это ошибка в программном обеспечении, при которой программа захватывает оперативную память, но не освобождает ее после использования.
    - Что такое reference counting (Подсчет ссылок)?
        Подсчет ссылок - это метод управления памятью, при котором каждый объект хранит количество указывающих на него ссылок. Используется как средство освобождения объектов, которые больше не нужны и на них нет ссылок
    - Что такое weak / strong reference (слабая / сильная ссылка)?
        Сильная ссылка - это стандартный тип ссылки, предоствращающий удаление объекта сборщиком мусора. Объект живет, пока на него ссылкается хотя бы одна такая ссылка.  
        Слабая ссылка не препятсвует удалению. Сборщик может удалить объект при след. цикле, даже если слабая ссылка указывает на него. (например кэширование, если памяти мало)
    - Что такое copy-on-write?
        Это оптимизационной подход, при котором данные не копируются физически сразу при запросе, а используется соместно (читаются из одного места). Копия создается только тогдаЮ когда происходит попытка изменить данные. Пример - В PHP, Swift, C++ многие структуры данных по умолчанию используют этот механизм для повышения производительности.
